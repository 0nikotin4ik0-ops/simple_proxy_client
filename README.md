🚀 Инструкция по запуску
Скачайте xray.exe с официального репозитория Xray-core и поместите в корень проекта.
(Важно) Для корректного импорта подписок программе нужен "шаблон". Положите любой рабочий .json конфиг в папку configs/ или назовите его template.json и положите в корень. Программа будет брать из него настройки потоков (streamSettings), подставляя только адреса и ключи из подписки.

Вставьте ссылку на подписку и нажмите Импорт.
Нажмите Пинг всех, выберите лучший сервер (или включите галочку автопереключения) и жмите Подключиться.
⚠️ Дисклеймер
Проект поставляется "как есть" (as-is). Используйте на свой страх и риск и не забывайте про законодательство вашей страны.
